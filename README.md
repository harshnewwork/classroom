# Mentors Studio — Classroom Booking Website

React 19 + Vite marketing and booking website for Mentors Studio classroom-rental facilities.

## Features
- Marketing pages for spaces, facilities, educators, pricing, and contact.
- WhatsApp & clipboard lead generation enquiry flow.
- Hidden administrative room status manager (`/#/manage-rooms-7f2a`) powered by Supabase Postgres.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Admin Backend Setup
For complete instructions on configuring Supabase, executing the database migrations, and provisioning admin accounts, see [SUPABASE_SETUP.md](./SUPABASE_SETUP.md).
